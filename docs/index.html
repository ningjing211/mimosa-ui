Mimosa
文件 套件 整合

Design system · documentation first

把 token、樣式契約與元件規則收斂成同一份文件。

Mimosa 是一個以 CSS token、Tailwind bridge 與 product primitives 為核心的前端樣式套件。本站作為 GitHub Pages 文件首頁，提供安裝方式、公開入口與元件規則入口。

進入完整文件 查看 package 入口
Quick start npm 
npm install mimosa-design-system

import "mimosa-design-system/tokens.css";
  • Foundation tokens、語意映射與視覺基底
  • Primitives 按鈕、面板、badge、表單與 state pattern
  • Reference 文件頁說明 package 入口與元件實作對照

Package 入口

現階段 package 對外提供穩定的 token 與 Tailwind bridge 入口；文件站本身不再作為 package CSS 輸出的一部分。

建議使用順序

入口 用途 適合場景
tokens.css 提供設計 token 與 CSS 變數 靜態頁、文件頁、非 Tailwind 專案
tailwind.css 供建置流程解析的 Tailwind bridge 入口 Vite / Tailwind v4 host app
tokens.json 給文件、工具鏈或 JS 讀取 token 生成 reference、同步設計資料

文件與整合

GitHub Pages 站點優先服務文件與規則查閱；完整元件範例、token 對照與實作說明集中在同一份文件頁。
