MVP 邊界說明

  • 僅支援公開活動，不含私人活動、邀請碼與受邀可見機制。
  • 不含票務、售票、報名審核、名額上限與候補流程。
  • 內容治理以事後檢舉為主，不含事前人工審核。
  • 探索頁只顯示未結束且未取消活動。
