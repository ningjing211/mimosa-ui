3) 推播通知

US-018

背景/關閉時觸發推播；當前聊天室前景中不觸發。

  • 觸發條件 App 在背景或關閉，且收到新訊息
  • 通知文案 收到一則新訊息
  • 點擊行為 直接導向對應聊天室

4) 聊天室安全控制

US-018-SAFE

聊天室內可檢舉/封鎖；解除配對與封鎖行為限制不同。

解除配對：聊天室保留可見，但輸入框停用不可發新訊息。

封鎖：雙方聊天室完全不可見。

禁聊：顯示限制提示，輸入功能停用。

MVP 邊界說明

  • 聊天僅限配對成功雙方，未配對不得互傳訊息。
  • MVP 不支援語音、影片與非圖片檔案傳送。
  • 聊天資料儲存於 Firebase Realtime Database，紀錄預設永久保存。
  • 推播內容不顯示訊息原文，僅顯示「收到一則新訊息」。
  • 解除配對與封鎖限制不同：解除後可見但不可傳；封鎖後完全不可見。
