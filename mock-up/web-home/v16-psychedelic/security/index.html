EPIC 5 / 安全機制 / P0

Safety and moderation flow

本頁對應 US-019～US-021，涵蓋使用者舉報、活動舉報、封鎖機制與自動限制處置。

1) 使用者舉報

US-019

使用者可舉報騷擾、詐騙、不當內容等違規行為。

2) 活動舉報

US-020

舉報處理對象為活動內容本身，不直接自動處罰建立者帳號。

  • 活動名稱：Warehouse Resonance
  • 目前舉報數：49
  • 門檻規則：達 50 次自動下架

3) 封鎖機制

US-021

封鎖後雙方完全不可見，立即中止後續互動。

封鎖生效範圍：配對卡片、聊天室、個人檔案、活動參加者頭像與其他入口。

封鎖結果：雙方完全不可見，且不可再互動。

解除配對差異：雙方仍可見，但不可再互動。

4) 自動限制處置

US-021-AUTO

達風險門檻時，自動觸發禁聊或下架，並保留稽核紀錄。

  • 帳號門檻：24 小時內 3 次有效舉報 → 暫時禁聊
  • 活動門檻：活動舉報達 50 次 → 自動下架
  • 禁聊附加限制：限制滑卡配對與建立活動功能
  • 聊天室影響：停用輸入功能並顯示限制提示
  • 稽核資料：保存舉報、封鎖、禁聊、下架紀錄

MVP 邊界說明

  • 封鎖生效後雙方於所有互動入口完全不可見。
  • 解除配對與封鎖邏輯不同：解除後可見但不可互動，封鎖後完全不可見。
  • 活動檢舉達 50 次自動下架；帳號 24 小時內 3 次有效舉報自動禁聊。
  • 禁聊同時限制滑卡配對與建立活動，聊天室輸入需停用並顯示提示。
  • 舉報、封鎖、禁聊與下架紀錄需完整保存供稽核。
