MVP 邊界說明

  • P0 僅支援一般滑卡配對，不以同活動參與為前提。
  • 同場配對列為 P1，與現場模式整合。
  • 配對池排除已封鎖、被封鎖、已下架、已配對、已解除與已略過對象。
  • 左滑略過對象不立即重現；更新照片可重新進入推薦名單。
  • 每日滑卡上限 50 次，超限後當日不可再左滑或右滑。
