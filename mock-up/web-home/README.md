# web-home mock-up variants

- `original/`：原版（目前 RA-like 簡潔版）  
- `v2-Neo-Brutalism/`：同一份 HTML 骨幹，改為 Neo-Brutalism 視覺樣式
- `v9-TaliwindCSS-Neo-Brutalism/`：同一份 HTML 骨幹，使用 Tailwind utility 組出 Neo-Brutalism 樣式（色彩仍吃 token）
- `v15-Neo-Brutalism-test/`：多風格實驗（含 `psychedelic/` 內聯樣式稿）
- `v16-psychedelic/`：**選定之 Psychedelic 定稿**；結構同 v15 psychedelic，設計系統對齊 v9（`theme-tokens.css` + `styles.css` + `DESIGN_LANGUAGE.md`）

## 使用方式

直接用瀏覽器開啟以下任一檔案：

- `mock-up/web-home/original/index.html`
- `mock-up/web-home/v2-Neo-Brutalism/index.html`
- `mock-up/web-home/v9-TaliwindCSS-Neo-Brutalism/index.html`
- `mock-up/web-home/v16-psychedelic/index.html`
- `mock-up/web-home/v16-psychedelic/design-system.html`（token 視覺化文件）
