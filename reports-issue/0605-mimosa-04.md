# 09 Report — 設定頁 Checkbox 天空藍勾選與邊框異常

**建立日期：** 2026-06-05  
**回報對象：** `mimosa-design-system` 維護者（§4～§5）；Rave Connect 前端（§3、§6）  
**關聯頁面：** `/my/settings` →「接受其他使用者邀請我參加活動」  
**實測環境：** Mobile `localhost`；`mimosa-design-system@0.3.2`；Chrome／Safari 原生 `<input type="checkbox">`

---

## 1. 摘要

| 項目 | 說明 |
|------|------|
| **使用者回報** | 勾選時 checkbox 變**天空藍**，與「想參加／Like」螢光綠語意不一致；外框 border 似消失，視覺突兀。 |
| **主因（消費端）** | 設定頁使用**裸** `<input type="checkbox">`，未套用 Mimosa `.form-choice` 或未設 `accent-color`。 |
| **主因（瀏覽器）** | 無 `accent-color` 時，UA 預設勾選色多為系統藍（非 Mimosa lime）。 |
| **主因（設計系統）** | Mimosa **已有** `.form-choice` + `accent-color: lime`，但 README 公開 class 表**未列出**；淺色 `psy-card` 上 `.form-choice` 文字色仍綁 `text-primary`（深底用），文件缺口。 |
| **非主因** | 非 `ion-checkbox` 元件；`--ion-color-primary` 未直接套用到原生 checkbox。 |

---

## 2. 截圖／現象

- 未勾選：小方框，邊框尚可辨識。
- 勾選後：填充色偏**天藍**，與 App 內 `psy-btn-primary`（萊姆／黃綠）主行動色不一致。
- 勾選後邊框對比下降，像「border 消失」——實為 UA 原生 checkbox 勾選態繪製方式，非 Mimosa brutal 邊框語意。

---

## 3. 程式證據

### 3.1 消費端（設定頁）

```html
<!-- apps/mobile/.../settings.page.html -->
<label class="settings__toggle">
  <input type="checkbox" ... />
  <span>接受其他使用者邀請我參加活動</span>
</label>
```

```css
/* settings.page.css — 僅 margin，無 accent／邊框 */
.settings__toggle input {
  margin-top: 0.2rem;
}
```

全專案 `accent-color`：**0 處**（grep 無匹配）。

### 3.2 Mimosa 已有規則（但未被套用）

```css
/* node_modules/mimosa-design-system/dist/tailwind/product.css */
.form-choice input[type="checkbox"],
.form-choice input[type="radio"] {
  accent-color: var(--psy-color-secondary-lime);
}
```

### 3.3 README 公開 class 表

僅列 `form-input`，**未列** `form-choice`／`form-choice-list`／checkbox 用法。

### 3.4 同類風險點

| 位置 | 狀況 |
|------|------|
| `settings.page.html` | 裸 checkbox ❌ |
| `register-form` 的 `auth-form__checkbox` | 裸 checkbox，無 `accent-color` ❌ |
| 全專案 | 無任何 `form-choice` class 使用 |

---

## 4. 歸屬分析

| 方 | 責任 |
|----|------|
| **Rave Connect** | 應使用 Mimosa `.form-choice` 或明確 `accent-color: var(--psy-color-secondary-lime)`；設定頁不應裸用原生 checkbox |
| **瀏覽器 UA** | 預設勾選色為系統藍，屬預期；需 CSS 覆寫 |
| **Mimosa** | ① README 未曝光 `form-choice`；② `.form-choice { color: text-primary }` 在 **淺色 psy-card** 上會白字（若直接套用需 on-light 變體）；③ 僅 `accent-color` 無法提供 neo-brutal 邊框，勾選態邊框仍偏 UA |

---

## 5. 請 Mimosa 維護者協助（Issue 建議）

### 5.1 文件

- 在 README「常用公開 Class」加入：`form-choice`、`form-choice-list`。
- 範例：設定頁／註冊 18+ 確認 checkbox。

### 5.2 淺色 surface 變體

```css
/* 建議 */
.form-choice-on-light {
  color: var(--psy-surface-card-fg);
}
.form-choice-on-light input[type="checkbox"] {
  accent-color: var(--psy-color-secondary-lime);
  /* 可選：outline / border 維持 brutal */
}
```

### 5.3 是否提供完整 checkbox primitive

`accent-color` 無法完全控制 border／勾勾形狀。若需與 `psy-btn-primary` 同系：

- 建議 `psy-checkbox`（自繪或 `appearance: none` + brutal border + lime checked bg）
- 或文件明確寫：「原生 checkbox 最低限度請用 `.form-choice` + `accent-color`」

### 5.4 與主行動色對照

| 語意 | 建議視覺 |
|------|----------|
| 主行動（Like、想參加） | `psy-btn-primary` 萊姆填色 |
| 設定開關／同意勾選 | 同系 `accent-color: --psy-color-secondary-lime` 或 `psy-checkbox--checked` |
| 避免 | 瀏覽器預設藍 |
